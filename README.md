# SQL Filtering Practice

## Project Overview
This project focuses on practicing SQL filtering techniques using an Employee dataset. It helps beginners understand how to retrieve specific records from a database using different SQL conditions.

## Objectives
- Learn SQL filtering techniques.
- Retrieve specific employee records.
- Filter data using different conditions.
- Sort employee records based on salary.

## Tools Used
- MySQL Workbench
- SQL

## Dataset
The project uses a sample Employee dataset containing 10 employee records.

**Columns:**
- EmployeeID
- Name
- Department
- City
- Salary
- Age

## SQL Concepts Covered
1. WHERE Clause
2. AND Operator
3. OR Operator
4. IN Operator
5. BETWEEN Operator
6. LIKE Operator
7. ORDER BY
8. ASC and DESC

## Project Queries
This project includes 12 SQL queries:

1. Find employees in the IT department.
2. Find employees earning more than 40,000.
3. Find employees from Delhi.
4. Find employees older than 25.
5. Find employees from Mohali earning more than 30,000.
6. Find employees in IT or HR.
7. Find employees from Delhi and Mumbai.
8. Find employees earning between 30,000 and 45,000.
9. Find employees whose names start with R.
10. Find employees whose names end with A.
11. Find employees earning less than 40,000.
12. Sort employees by salary in descending order.

## Learning Outcomes
- Improved understanding of SQL queries.
- Learned how to filter records.
- Practiced multiple SQL operators.
- Developed basic database querying skills.

## Conclusion
This project helped me understand SQL filtering commands and how to retrieve meaningful information from employee data using MySQL.
